# طباعة سريعة (PrintEasy) 🖨️

تطبيق متقدم وسهل الاستخدام للطباعة على الطابعات الحرارية المحمولة عبر **Bluetooth** و **USB**، مع دعم الطباعة من قائمة المشاركة ومحرر قوالب بالسحب والإفلات.

## ✨ المميزات
- اتصال Bluetooth Classic + BLE + USB OTG
- دعم عربي كامل (Raster Rendering)
- محرر قوالب نصي + محرر مرئي Drag & Drop
- طباعة جماعية من CSV/Excel
- طباعة من قائمة المشاركة
- سجل طباعة مع إعادة طباعة
