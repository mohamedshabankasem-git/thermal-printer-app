# PrintEasy — طباعة سريعة

تطبيق Android للطباعة الحرارية عبر Bluetooth.

## البداية الحالية
هذه أول نسخة نظيفة من المشروع، مبنية بـ Flutter. تشمل هيكل التطبيق والواجهة الأساسية وإدارة اتصال Bluetooth واختيار الطابعة وحفظها محليًا.

## المتطلبات
- Flutter stable
- Android Studio / Android SDK
- Java 17

## التشغيل
```bash
flutter pub get
flutter run
```

## البناء
```bash
flutter build apk --release
```

## خارطة الطريق
1. تأسيس التطبيق وإعدادات Android وواجهة البداية.
2. اكتشاف طابعات Bluetooth والاقتران والاتصال وحفظ الطابعة.
3. محرك طباعة ESC/POS ودعم العربية.
4. مقاسات 58 و80 مم والورق بكره.
5. المشاركة إلى التطبيق والطباعة المباشرة.
6. إعدادات الطباعة والمعاينة وسجل الطباعة.
